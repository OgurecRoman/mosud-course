# Практическая работа №5

Вариант 10: S = {AL, SE, BA}. Ищем товарные категории, которые встречались в доставленных заказах покупателей каждого штата из S. Категории с `NULL` и пустой строкой исключены.
Запуск: `psql -U postgres -d olist -q -o result.txt -f lab05.sql`

## Контрольные вопросы

1. **Как переписать «для всех x выполняется P(x)» через «не существует»?** `∀x P(x) ≡ ¬∃x ¬P(x)`. В SQL: `NOT EXISTS (SELECT ... WHERE NOT P(x))`. Для деления получается двойной `NOT EXISTS`: нет такого штата из S, для которого нет соответствия.
2. **Почему `COUNT(DISTINCT state)` должен сравниваться с мощностью делителя?** Категория покрывает все штаты S, только если число различных штатов из S, где она встречается, равно числу штатов в S. Без `DISTINCT` повторные заказы из одного штата дали бы завышенное значение, а сравнение с мощностью делителя гарантирует, что нет ни одного пропущенного штата.
3. **Что происходит с универсальным условием, если множество обязательных элементов пусто?** Оно истинно для любого объекта (вакуумная истинность): нарушить условие нечем. Двойной `NOT EXISTS` и `EXCEPT` возвращают все категории, а `HAVING COUNT` даёт пустой результат, то есть ведёт себя иначе.
