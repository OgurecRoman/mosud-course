# Практическая работа №3

Вариант 10: отношение `products`, предикат `category IS NOT NULL` и объём `length·height·width > 20 000 см³`.
Запуск: `psql -U postgres -d olist -q -o result.txt -f lab03.sql`

## Реляционное выражение

Переименование: `product_category_name → category`, `product_length_cm → length`, `product_height_cm → height`, `product_width_cm → width`

## Контрольные вопросы

1. **Какие свойства выборки позволяют менять порядок нескольких фильтров?** Выборки коммутативны, `σ₁(σ₂(R)) = σ₂(σ₁(R))`, а также `σ[P₁ ∧ P₂](R) = σ₁(σ₂(R))`. Поэтому сначала можно применять самый селективный фильтр.
2. **Почему проекция в математической модели устраняет повторяющиеся кортежи, а SELECT в SQL — нет?** Отношение в модели — множество, и одинаковых кортежей в нём не бывает. SQL работает с мультимножествами, поэтому дубликаты остаются, пока их не уберёт `DISTINCT`. К тому же проверка уникальности дорогая.
3. **Что означает замкнутость операций реляционной алгебры?** Результат любой операции сам является отношением. Поэтому операции можно вкладывать друг в друга и строить выражения и деревья любой глубины.
