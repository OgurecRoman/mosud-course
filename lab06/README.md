# Практическая работа №6

Вариант 10: повторные покупатели, суммарные расходы которых выше среднего среди повторных покупателей. Покупатель определяется по `customer_unique_id`, повторный — 2 и более заказа со статусом `delivered`, расходы — сумма `payment_value` по этим заказам. Повторных покупателей 2801, средние расходы 308.59, выше среднего 919.
Запуск: `psql -U postgres -d olist -q -o result.txt -f lab06.sql`

## Контрольные вопросы

1. **Чем коррелированный подзапрос отличается от независимого?** Независимый подзапрос не ссылается на столбцы внешнего запроса и вычисляется один раз. Коррелированный использует значения текущей строки внешнего запроса, поэтому логически вычисляется для каждой строки отдельно (оптимизатор PostgreSQL может преобразовать его, например, в semi join).
2. **В каких случаях EXISTS логически удобнее IN?** Когда нужно проверить только наличие строк, особенно по нескольким условиям или с корреляцией (как «есть другой доставленный заказ этого покупателя»). `EXISTS` не зависит от `NULL` в подзапросе, а `NOT IN` при наличии `NULL` в списке никогда не становится истинным.
3. **Почему скалярный подзапрос должен возвращать не более одной строки?** Он подставляется туда, где ожидается одно значение (например, `total_spent > (SELECT ...)`). Если строк больше одной, PostgreSQL выдаёт ошибку `more than one row returned by a subquery used as an expression`. Если строк нет, результат `NULL`.
